## 🤝 How to Contribute

1. **Add a new idea:**
   ```bash
   mkdir your-idea-name
   cd your-idea-name
   touch README.md
   ```

2. **Document your idea:**
   - Create a `README.md` in your app directory
   - Include: Description, Features, Tech Stack, Roadmap

3. **Update main README:**
   - Add your idea to [Ideas](#ideas) section
   - Include status and priority

4. **Submit changes:**
   ```bash
   git add .
   git commit -m "feat: add [your-idea-name] to collection"
   git push origin main
   ```
